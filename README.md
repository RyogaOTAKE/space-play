# Space Play

宇宙の事象を、時間を動かしながら体験するサイトです。

## 体験

- **太陽系クルーズ** — 惑星の公転速度の差を追います。惑星をクリックすると追跡対象が変わります。
- **事象の地平線** — 降着円盤と探針の落下を見ます。画面クリックで探針を打ち出します。
- **日食と月食** — 太陽・地球・月の配置を動かし、食分の変化を見ます。
- **重力アシスト** — 探査機が惑星近傍を通過して加速する様子を見ます。

距離や時間は体験しやすさのために圧縮しています。軌道力学の厳密解ではありません。

## 起動

ES Modules を使うため、ファイルを直接開かず HTTP で配信します。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。
