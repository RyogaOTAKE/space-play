# Space Play

宇宙の事象を、時間を動かしながら体験するサイトです。

## 体験

- **太陽系クルーズ** — 惑星の公転速度の差を追います。下の惑星名をクリックすると追跡対象が変わります。
- **事象の地平線** — 降着円盤のガスが黒い円 (事象の地平線) へらせん状に落ちて消え、クリックした探針も吸収されます。
- **日食と月食** — 左に配置、右上に地球から見た欠けを同時に出します。地球上の影の地点も印します。
- **重力アシスト** — 探査機が惑星の後ろ側を通ると加速、前側を通ると減速します。太陽基準の速さと惑星基準の速さを同時に見ます。通過結果は消さずに表示します。

距離や時間は体験しやすさのために圧縮しています。軌道力学の厳密解ではありません。

## 起動

ES Modules を使うため、ファイルを直接開かず HTTP で配信します。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。
